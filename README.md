# E-Commerce Sales Analysis

An Excel-based Capstone Project analyzing 2000 E-Commerce orders to find sales trends by Category, Region, and Customer Loyalty.

## 📊 Live Dashboard
![Dashboard](Screenshots/Dashboard.png)

## 🚀 Project Overview
Analyzed 2000 orders to answer 3 questions:
1. Which category sells the most?
2. Which region is underperforming?
3. Which customer type spends the most?

**Key Result:** Total Sales Rs. 21,74,024 | Top Category: Sports | Weak Region: West (12%)

## 🛠️ Tools Used
- Microsoft Excel
- PivotTables & Pivot Charts
- Slicers & Interactive Dashboard

## 📂 Dataset
- **Source:** Kaggle / Provided Dataset
- **Size:** 2000 rows, 10 columns
- **Columns:** Order ID, Category, Store_Region, Loyalty_Level, Quantity, Total Amount, Order Date

## 🔍 How to Run
1. Download / Clone this repo
2. Open `E-Commerce_Dashboard.xlsx` in Excel
3. Go to `Dashboard` sheet
4. Use Slicers to filter by Category, Region, Loyalty

No code or setup needed. Excel only.

## 📈 Key Insights
- **Total Sales:** Rs. 21,74,024 from 2000 orders
- **Top Category:** Sports - Rs. 5,42,003
- **Top Region:** North - 30%
- **Weak Region:** West - Only 12%
- **Best Customers:** Platinum - Highest sales

## 💡 Recommendation
Focus marketing on West region and give extra offers to Platinum & Gold customers. Sales can improve by 10-15% in next quarter.
